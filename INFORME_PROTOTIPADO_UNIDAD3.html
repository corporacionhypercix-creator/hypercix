1. Objetivo del Proyecto

El objetivo de este avance fue transformar el prototipo del website HYPERCIX (desarrollado en la Unidad 2) en una experiencia de usuario dinámica, escalable y validada. Se implementaron interacciones avanzadas, microinteracciones y se estructuró un Design System funcional que garantiza la consistencia visual y técnica del proyecto. Adicionalmente, se realizaron pruebas de usabilidad enfocadas en estas interacciones para validar su efectividad.

Alcance del prototipo

HYPERCIX es una plataforma web de cotización de equipos de seguridad electrónica (cámaras, alarmas, redes, servicios). El prototipo comprende:

  • Página pública: Catálogo de productos con búsqueda, filtros, detalle modal y carrito de cotización.
  • Panel de administración: 10 módulos para gestión de productos, categorías, marcas, clientes, cotizaciones, inventario, banners, tipo de cambio, configuración y dashboard.
  • Backend: Servidor Node.js + Express con base de datos SQLite persistente, desplegado en Render.

El sitio está disponible en: https://hypercix.onrender.com

2. Archivo de Prototipo Interactivo

El prototipo de alta fidelidad fue desarrollado como sitio web funcional (HTML, CSS, JavaScript vanilla) con flujos de navegación completos, transiciones y microinteracciones. A continuación se describen las pantallas, microinteracciones y curvas de tiempo implementadas.

2.1 Pantallas del prototipo

Pantalla 1 – Página principal / Catálogo

Landing page con hero, categorías, grid de productos con tarjetas, strip de marcas, footer. Desde aquí el usuario puede buscar productos, filtrar por categoría/marca y agregar al carrito.

Pantalla 3 – Carrito flotante / Formulario de cotización

Panel lateral que se despliega con los productos agregados, controles de cantidad (+/-), total estimado y formulario de solicitud (nombre, email, teléfono, mensaje).

2.2 Microinteracciones implementadas

Se implementaron 6 microinteracciones clave (superando el mínimo de 5 requerido):

M1. Hover en tarjetas de producto 200ms

Al pasar el mouse, la tarjeta escala 1.02 y aparece un overlay semitransparente con botón de "Ver detalles".

M2. Botón "Cotizar +" con escala 120ms

Al hacer clic, el botón escala a 1.06 con sombra, luego vuelve a 0.95 (efecto de rebote) y regresa a 1.0.

M3. Badge del carrito (pop) 200ms

Al agregar un producto, el badge del carrito escala a 1.18 y regresa, simulando un latido que notifica al usuario.

M4. Tooltip en logos de marcas 150ms

Al hover sobre un logo de marca, aparece un tooltip "Ver productos de [marca]" con fade-in.

M5. Spinner en botón de envío 300ms

Al enviar cotización, el botón muestra un spinner giratorio y se deshabilita, evitando dobles envíos.

M6. Modal fade-in con overlay 250ms

El modal de detalle de producto aparece con una animación de opacidad y escala (0.9 → 1.0) con overlay oscuro.

3.3 Patrones de diseño

  • Patrón de grid responsivo: El grid de productos usa grid-template-columns: repeat(auto-fill, minmax(240px, 1fr)) adaptándose a cualquier tamaño de pantalla.
  • Patrón de modal: Todos los detalles de producto se muestran en un modal centrado con overlay, cerrable con clic fuera, tecla Escape o botón X.
  • Patrón de carrito lateral: El carrito de cotización es un panel fijo que se desliza desde la derecha, con formulario integrado.
  • Patrón de filtrado: Los filtros de categoría y marca actualizan el grid en tiempo real mediante eventos input y change.
  • Patrón de sincronización: Los datos se sincronizan entre admin y página pública cada 15 segundos mediante polling a la API.
