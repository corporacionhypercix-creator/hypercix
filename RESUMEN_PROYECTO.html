Características implementadas

Tienda pública

  • Catálogo de productos con tarjetas
  • Búsqueda por texto, categoría y marca
  • Modal de detalle con imágenes y ficha técnica
  • Botón "Cotizar +" en cada tarjeta
  • Carrito flotante con formulario de cotización
  • Sección de marcas con logos
  • Sincronización cada 15s con el servidor
  • WhatsApp flotante
  • Diseño responsive oscuro

Panel admin

  • Autenticación con tokens
  • CRUD completo de productos, categorías, marcas
  • Importación CSV de productos
  • Gestión de cotizaciones recibidas
  • Configuración de tienda (logo, moneda, impuesto)
  • Tipo de cambio con historial
  • Subida de imágenes (archivo o URL)
  • Tema claro/oscuro
  • Sidebar con navegación completa

Correcciones aplicadas

ProblemaSolución
Datos se perdían al reiniciar RenderDisco persistente en render.yaml + sesiones en SQLite
Módulos admin sobrescribían datos del servidor con defaultsSe eliminó escritura de defaults al iniciar; ahora esperan sync del servidor (evento store-synced)
Botón "Pagar" confundía usuariosCambiado a "Cotizar"
No había botón "Agregar" en tarjetas de productoAgregado botón "Cotizar +" con clase btn-buy
Logo no persistía para todos los visitantesLogo URL ahora se guarda en settings del admin y se sirve vía API
Menú móvil no funcionabaSe agregó event handler al botón hamburguesa
